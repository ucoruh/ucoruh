## Research

Post-quantum and white-box cryptography (ML-KEM), authentication and key management for M2M/IoT and vehicular networks, IEEE 1609.2 V2X security, eSIM/SIM key renewal and revocation.

Selected work:
- **PQ-WB-KEM: Toward a White-Box Construction of ML-KEM-768 with Arithmetic Masking for M2M Communications** — *Mathematics* 14(17), 3072 (2026). [doi:10.3390/math14173072](https://doi.org/10.3390/math14173072)
- **A LoRa-Based Multi-Entity V2X Messaging Testbed for Cooperative ITS** — UBMK 2026. [doi:10.1109/UBMK71847.2026.11745154](https://doi.org/10.1109/UBMK71847.2026.11745154)
- **ESAR: Enhanced Secure Authentication and Revocation Scheme for Vehicular Ad Hoc Networks** — *J. Inf. Secur. Appl.* 64 (2022). [doi:10.1016/j.jisa.2021.103081](https://doi.org/10.1016/j.jisa.2021.103081)
- **Hybrid Secure Authentication and Key Exchange Scheme for M2M Home Networks** — *Secur. Commun. Netw.* (2018). [doi:10.1155/2018/6563089](https://doi.org/10.1155/2018/6563089)
